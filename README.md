## Домашнее задание к работе 6 (вар.32)
### Условие задачи
Даны произвольные числа A, B, C. Если нельзя построить треугольник с такими длинами сторон, то вывести «не треугольник», иначе напечатать «равносторонний треугольник» или «равнобедренный» или какой либо иной.
### 1. Реализация программы
```
#define _CRT_SECURE_NO_WARNINGS
#include <stdio.h>
#include <locale.h>

void zadanie3() {
    double A, B, C;
    printf("Введите три стороны треугольника A, B, C: ");
    scanf("%lf %lf %lf", &A, &B, &C);

    if (A + B <= C || A + C <= B || B + C <= A) {
        printf("не треугольник\n");
    }
    else if (A == B && B == C) {
        printf("равносторонний треугольник\n");
    }
    else if (A == B || A == C || B == C) {
        printf("равнобедренный треугольник\n");
    }
    else {
        printf("разносторонний треугольник\n");
    }
}

int main() {
    setlocale(LC_ALL, "rus");
    zadanie3();

    return 0;
}
```
